# Contributing

Contributions are welcome for the generic Android site-management client, its protocol, accessibility, documentation and tests.

Please keep contributions generic and reusable:

- do not commit customer credentials, API tokens, keystores or production configuration;
- use example domains and synthetic data in documentation and tests;
- keep server-provided modules explicit and permission-aware;
- document any remote action that can modify a managed site;
- preserve secure update and authentication boundaries;
- run the available unit/lint checks before proposing a change.

Report vulnerabilities privately using `SECURITY.md`.

Contributions are provided under AGPL-3.0-only.
