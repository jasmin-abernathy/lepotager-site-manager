# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the application is pre-1.0.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Send a private report to `contact@lepotager.org` with the subject `Security — Site Manager`. Include the affected commit, reproduction steps, impact and any suggested mitigation.

Never include real site credentials, API tokens, keystores, customer data or production configuration in a report. Use synthetic examples.

Particular attention should be paid to server-provided modules, authentication, remote actions, WebView/network boundaries and update integrity.
